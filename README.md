## Project Title
InGrid

## Product Description
InGrid is a web-based application designed to help address the housing crisis in the province by simplifying how people search for homes. Instead of using multiple platforms to find short-term rentals, long-term leases, or mortgage-based properties, InGrid provides a single, centralized solution.

The platform allows users to browse and compare housing listings across different categories, making it easier to find the option that best fits their needs and budget. In addition, InGrid offers integrated furniture recommendations and purchasing options, helping users select furniture that complements their chosen home.

By combining housing search, comparison tools, and home furnishing in one application, InGrid aims to make the housing search process more efficient, transparent, and user-friendly.

## Need and Value
InGrid  emphasizes on verified accounts  for both the buyer and seller  to ensure safety on both sides and secure payments  for user focusing on protection and privacy

## Stakeholders:
The primary stakeholders of InGrid are members of the general population, including individuals and families seeking housing solutions such as short-term rentals, long-term leases, or home ownership within the province.

## Technology Requirements
Frontend:
The frontend will be developed using React.js to provide a responsive and user-friendly interface.

Backend:
The backend will be implemented using Node.js, responsible for handling application logic, authentication, and communication between the frontend and the database.

Database:
MySQL will be used as the relational database system. The database will manage and store user details, seller accounts, and unique identification (IDs) for users and sellers. It will also store housing listings, comparison data, and transaction-related information to ensure accurate tracking and data integrity across the system. 


## Project Status
This project is in the early stages of development. Features and implementation details are subject to change as the project evolves.
